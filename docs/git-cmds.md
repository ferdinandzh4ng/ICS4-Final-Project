# Git Commands

## Pushing changes(used when you want to commit/push changes to your branch, run in order):
1. git add .
2. git commit -m "your commit message"
3. git push (if this fails in terminal you'll see smtg like git push set-upstream ..., copy that and run it again)

## Creating a new branch:
1. First go to main branch: git checkout main
2. Create a new branch: git checkout -b branch-name
3. Go into an existing branch: git checkout branch-name

## Pulling from main(use this if your local main is behind, if someone else pushed changes to main):
git pull
